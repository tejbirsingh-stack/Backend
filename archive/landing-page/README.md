# Noah Landing Page

A clean, modern landing page for Noah Media Asset Management platform.

## Contents

- `index.html` - The full landing page with features, hero section, and login form
- `login.html` - Minimal login page with just logo and login form
- `noah-logo.png` - Noah logo in PNG format
- `README.md` - This documentation file

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with gradient backgrounds and glass-morphism effects
- **Animations**: Smooth fade-in animations for enhanced user experience
- **Single Page**: Complete landing page in one HTML file for easy deployment
- **Self-Contained**: All styles are embedded, no external dependencies required
- **Basic Authentication**: Preset credentials for demo access

## Usage

Simply upload the entire `landing-page` folder to your web server. 

- **Full Landing Page**: Use `index.html` for a complete demonstration with features and information
- **Minimal Login**: Use `login.html` for a clean, focused login experience

Both pages redirect to the Iconik demo after successful login.
