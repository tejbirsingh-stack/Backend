# Noah Enterprise Deployment Guide

## Overview

This guide provides comprehensive instructions for deploying Noah with enterprise-grade reliability and scale across multiple regions with disaster recovery capabilities.

## Architecture Overview

Noah is deployed as a highly available, multi-region platform with:

- **Primary Region**: us-east-1 (N. Virginia)
- **Secondary Region**: eu-west-1 (Ireland)  
- **Tertiary Region**: ap-southeast-1 (Singapore)

### Key Components

1. **Kubernetes (EKS)**: Container orchestration
2. **Aurora PostgreSQL**: Primary database with global database
3. **ElastiCache Redis**: In-memory cache with global datastore
4. **Backblaze B2**: Object storage for media assets
5. **CloudFront**: Global CDN
6. **Istio**: Service mesh for traffic management

## Deployment Steps

### 1. Infrastructure Provisioning

#### Deploy Terraform Infrastructure
```bash
# Initialize Terraform
cd terraform/
terraform init

# Review plan
terraform plan -out=tfplan

# Apply infrastructure
terraform apply tfplan

# Save outputs
terraform output -json > outputs.json
```

#### Verify Infrastructure
```bash
# Check VPCs
aws ec2 describe-vpcs --filters "Name=tag:Project,Values=Noah"

# Check databases
aws rds describe-db-clusters --db-cluster-identifier noah-production-primary

# Check Redis
aws elasticache describe-replication-groups

# Check B2 bucket
b2 get-bucket noah-production-media-assets
```

### 2. Kubernetes Setup

#### Configure kubectl
```bash
# Update kubeconfig for primary cluster
aws eks update-kubeconfig --name noah-production --region us-east-1

# Verify connection
kubectl cluster-info
kubectl get nodes
```

#### Install Core Components
```bash
# Create namespaces
kubectl apply -f k8s/namespaces/

# Install service mesh (Istio)
istioctl install --set profile=production -y
kubectl label namespace noah-production istio-injection=enabled

# Install cert-manager
kubectl apply -f https://github.com/cert-manager/cert-manager/releases/download/v1.13.0/cert-manager.yaml

# Install metrics-server
kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml
```

#### Deploy Secrets
```bash
# Create database secret
kubectl create secret generic noah-db-secret \
  --from-literal=url="postgresql://noah:${DATABASE_PASSWORD}@$(terraform output -raw primary_database_endpoint)/noah" \
  -n noah-production

# Create Redis secret
kubectl create secret generic noah-redis-secret \
  --from-literal=url="rediss://default:${REDIS_AUTH_TOKEN}@$(terraform output -raw redis_primary_endpoint):6379" \
  -n noah-production

# Create B2 secret
kubectl create secret generic noah-b2-secret \
  --from-literal=application_key_id="${B2_APPLICATION_KEY_ID}" \
  --from-literal=application_key="${B2_APPLICATION_KEY}" \
  -n noah-production
```

### 3. Application Deployment

#### Deploy Core Services
```bash
# Apply configurations
kubectl apply -f k8s/configmaps/
kubectl apply -f k8s/services/
kubectl apply -f k8s/deployments/

# Wait for rollout
kubectl rollout status deployment/noah-api -n noah-production
kubectl rollout status statefulset/noah-compression-worker -n noah-production

# Verify pods
kubectl get pods -n noah-production
kubectl get svc -n noah-production
```

#### Configure Autoscaling
```bash
# Apply HPA and VPA
kubectl apply -f k8s/autoscaling/

# Verify autoscaling
kubectl get hpa -n noah-production
kubectl get vpa -n noah-production
```

### 4. Monitoring Setup

#### Deploy Prometheus Stack
```bash
# Add Prometheus Helm repo
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm repo update

# Install kube-prometheus-stack
helm upgrade --install prometheus prometheus-community/kube-prometheus-stack \
  --namespace monitoring \
  --create-namespace \
  --values monitoring/prometheus-values.yaml \
  --set prometheus.prometheusSpec.retention=30d \
  --set prometheus.prometheusSpec.storageSpec.volumeClaimTemplate.spec.resources.requests.storage=200Gi

# Apply custom rules
kubectl apply -f monitoring/prometheus-rules.yaml
```

#### Deploy Grafana Dashboards
```bash
# Import dashboards
kubectl create configmap noah-dashboards \
  --from-file=monitoring/dashboards/ \
  -n monitoring

# Restart Grafana to load dashboards
kubectl rollout restart deployment/prometheus-grafana -n monitoring
```

#### Setup Log Aggregation
```bash
# Install Loki
helm upgrade --install loki grafana/loki-stack \
  --namespace monitoring \
  --values monitoring/loki-values.yaml

# Install Fluent Bit
helm upgrade --install fluent-bit fluent/fluent-bit \
  --namespace monitoring \
  --values monitoring/fluent-bit-values.yaml
```

### 5. Configure CDN and WAF

#### Update CloudFront
```bash
# Get distribution ID
DISTRIBUTION_ID=$(aws cloudfront list-distributions \
  --query "DistributionList.Items[?Comment=='Noah production CDN'].Id" \
  --output text)

# Update origin settings
aws cloudfront update-distribution \
  --id $DISTRIBUTION_ID \
  --distribution-config file://cloudfront-config.json

# Create invalidation
aws cloudfront create-invalidation \
  --distribution-id $DISTRIBUTION_ID \
  --paths "/*"
```

#### Enable WAF Rules
```bash
# Associate WAF with CloudFront
aws wafv2 associate-web-acl \
  --web-acl-arn $(terraform output -raw waf_acl_arn) \
  --resource-arn arn:aws:cloudfront::123456789012:distribution/$DISTRIBUTION_ID
```

### 6. Setup Disaster Recovery

#### Configure Cross-Region Replication
```bash
# Enable S3 cross-region replication
aws s3api put-bucket-replication \
  --bucket noah-production-dr-us-east-1 \
  --replication-configuration file://s3-replication-config.json

# Test database failover
aws rds failover-db-cluster \
  --db-cluster-identifier noah-production-primary \
  --target-db-instance-identifier noah-production-primary-2
```

#### Create Backup Jobs
```bash
# Apply backup configuration
aws backup put-backup-plan --backup-plan file://backup-plan.json

# Create initial backup
aws backup start-backup-job \
  --backup-vault-name noah-production-vault \
  --resource-arn $(terraform output -raw primary_database_arn) \
  --iam-role-arn $(terraform output -raw backup_role_arn)
```

## Verification Steps

### 1. Health Checks
```bash
# API health
curl -f https://api.noah.app/health || exit 1

# Check all pods are running
kubectl get pods -n noah-production -o json | \
  jq -e '.items[] | select(.status.phase != "Running") | empty'

# Verify metrics
curl -s http://prometheus.noah.app/api/v1/query?query=up | \
  jq '.data.result[] | select(.metric.job == "noah-api") | .value[1]'
```

### 2. Performance Tests
```bash
# Run load test
k6 run --vus 100 --duration 5m tests/load-test.js

# Check response times
curl -w "@curl-format.txt" -o /dev/null -s https://api.noah.app/health
```

### 3. Failover Testing
```bash
# Test DNS failover
dig api.noah.app +short

# Simulate region failure
./scripts/simulate-region-failure.sh us-east-1

# Verify traffic routes to secondary
curl -I https://api.noah.app | grep -i x-region
```

## Rollback Procedures

### Application Rollback
```bash
# List deployment history
kubectl rollout history deployment/noah-api -n noah-production

# Rollback to previous version
kubectl rollout undo deployment/noah-api -n noah-production

# Rollback to specific version
kubectl rollout undo deployment/noah-api --to-revision=42 -n noah-production
```

### Infrastructure Rollback
```bash
# Revert Terraform changes
cd terraform/
terraform plan -destroy -target=module.problematic_resource
terraform destroy -target=module.problematic_resource
```

## Troubleshooting

### Common Issues

#### Pods Crash Looping
```bash
# Check pod logs
kubectl logs -p  -n noah-production

# Describe pod for events
kubectl describe pod  -n noah-production

# Check resource limits
kubectl top pod  -n noah-production
```

#### Database Connection Issues
```bash
# Test connection from pod
kubectl exec -it deployment/noah-api -n noah-production -- \
  psql $DATABASE_URL -c "SELECT 1"

# Check connection pool
kubectl exec -it deployment/noah-api -n noah-production -- \
  psql $DATABASE_URL -c "SELECT count(*) FROM pg_stat_activity"
```

#### High Memory Usage
```bash
# Check memory usage
kubectl top pods -n noah-production --sort-by=memory

# Get heap dump
kubectl exec -it  -n noah-production -- \
  jmap -dump:format=b,file=/tmp/heapdump.hprof 1

# Copy heap dump locally
kubectl cp noah-production/:/tmp/heapdump.hprof ./heapdump.hprof
```

## Security Considerations

### Network Policies
- All ingress traffic goes through Istio gateway
- Pod-to-pod communication restricted by NetworkPolicy
- Egress restricted to known endpoints

### Secrets Management
- All secrets stored in Kubernetes secrets
- Encryption at rest enabled
- Regular rotation schedule

### Compliance
- TLS 1.2+ enforced
- Data encrypted in transit and at rest
- Audit logging enabled
- RBAC configured with least privilege

## Cost Optimization

### Resource Recommendations
- Use Spot instances for non-critical workloads
- Enable cluster autoscaler
- Right-size instances based on metrics
- Use S3 lifecycle policies
